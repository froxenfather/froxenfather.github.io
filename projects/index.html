Projects

Couple of things so far.

Major project

Autonomous Drone Navigation

Developed autonomous navigation and mission-control software for utility infrastructure inspection drones at Los Alamos National Laboratory, then coordinated getting that software from simulation into the field.

Technologies
ROS 2, PX4
My role
Built the navigation and mission-control software, and the testing and debugging workflows used to validate it against real hardware.
The problem
Reliable autonomous inspection of utility infrastructure without a pilot on every flight.
Hard part
Diagnosing synchronization, timing, and navigation failures that only appeared once the software moved from simulation to physical hardware.
Outcome
Improved autonomous control reliability across both simulated and physical environments, and left behind GitHub documentation of failures and decisions that cut down repeated issues.
Learned
How much of "autonomy" is actually disciplined debugging of the sim-to-real gap, not the navigation algorithm itself.
Link
Not public — lab research.

Custom Unity Movement Controller

Technologies
Unity, C#
Outcome
Fully custom physics movement, no Rigidbody dependency.
